Welcome to GIFx 🎉

Welcome to GIFx! This site is designed to be a fun and simple way to explore random and curated GIFs — with no login required.

To enable basic functionality like favorites and reports, we generate a random anonymous ID for your browser. This keeps the site lightweight and private — without needing accounts or emails.

To Browse through random GIFs, click the 🔀-Button at them bottom to get started.

If you see a GIF you like, you can click the ⭐️-Button to add it to your Favorites.

If you want to directly use it on the Site, click the 📋-Button to copy the Name to your Clipboard, ready to paste it in the CB Chat.

If you come across an explicit or inappropriate GIF in a list that’s meant to be safe, please use the ⚠️-Button. Your feedback helps keep things clean.

Note: If this feature gets abused, I may need to switch to a login system to prevent misuse — which would make things a bit more annoying for everyone. So please use the tools responsibly 💚
